If Windows warns about or blocks "assets/script.txt" after unzipping, that's
just Windows being extra cautious about a file that came from a downloaded zip
- it's plain JavaScript for the site (renamed away from .js on purpose so Windows
doesn't treat it as a script to run). Right-click the .zip file itself (before or
after extracting) -> Properties -> check "Unblock" -> OK, then extract again -
that clears every file inside at once, no per-file warnings.
